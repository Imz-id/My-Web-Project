# IMVION - Personal Portal & Documentation

Website statis responsif yang dibuat khusus untuk dokumentasi pribadi dan kumpulan tools. Dioptimalkan agar ringan, cepat, dan mudah di-host menggunakan **GitHub Pages**.

## 🛠 Struktur Folder

```text
/
├── index.html           # Halaman utama (Hero section)
├── tools.html           # Daftar Tools dengan fitur live search
├── documentation.html   # Kumpulan artikel/tutorial
├── about.html           # Halaman profil singkat
├── css/
│   └── style.css        # Seluruh stylesheet & tema (Light/Dark)
├── js/
│   ├── config.js        # File KONFIGURASI UTAMA (Ganti nama web & gambar di sini)
│   ├── tools.js         # Daftar/database list tools
│   ├── documentation.js # Daftar/database dokumentasi
│   └── main.js          # Logika inti (Theme toggle, navbar, search)
└── assets/
    ├── images/          # Taruh foto background, logo, dll di sini
    └── icons/           # Aset icon
